## 0. 결론

**calibration으로 얻을 것이 없습니다. 시도하면 크게 잃습니다.**

같은 시즌에서 적합하면 상한만큼(2023 **+162.9**, 2024 **+55.2** BSS) 회수되지만,
**한 시즌 앞에서 적합해 다음 시즌에 적용하면 전부 큰 음수**입니다.

| 2023 → 2024 (배포 가능한 유일한 방식) | dBSS |
|---|---|
| temperature | **−105.8 ± 9.8** (10.8σ) |
| Platt | **−100.4 ± 9.7** (10.4σ) |
| isotonic | **−141.1 ± 11.0** (12.9σ) |

역방향(2024→2023)도 −41.7 ~ −149.5로 동일합니다. 방향·방법을 불문하고 음수입니다.

원인은 §4에 있습니다 — **v9의 잔여 miscalibration은 시즌마다 부호가 뒤집힙니다.**

## 1. 감사를 규정하는 불변성

`metrics.decomp`는 `pd.qcut(p, 50)`, 즉 **예측값의 분위수**로 구간을 나눕니다.
**강한 단조 변환은 모든 행을 같은 분위 구간에 남겨 두므로** 구간별 실제 비율과
가중치가 그대로이고,

> **Resolution은 단조 calibration 하에서 정확히 불변입니다.**

temperature · Platt · isotonic은 전부 단조입니다. 따라서

- calibration은 **Resolution을 1점도 더할 수 없고**
- 얻을 수 있는 최대치는 **현재 Reliability가 상한**입니다.

실측이 이를 확인합니다. temperature와 Platt의 `dRes`는 **모든 경우에 정확히
+0.0**입니다. isotonic만 ±2~34로 흔들리는데, 계단 함수가 동점(tie)을 만들어
분위 구간을 병합하기 때문입니다 — 엄밀한 단조성이 깨진 결과입니다.

이 불변성 덕에 감사가 값쌉니다. 남는 질문은 하나뿐입니다:
**맵이 시즌을 넘어 전이되는가.**

## 3. Reliability curve

`reliability_2023.csv`, `reliability_2024.csv` (20 분위 구간).

```
--- 2023   BSS 403.1  Res 558.7  Rel 155.0 ---
--- 2024   BSS 917.2  Res 960.3  Rel  42.9 ---
```

**2023이 훨씬 더 어긋나 있습니다.** 2023 gap의 sd는 0.0186, 2024는 0.0064로
**3배** 차이입니다. 2023의 어긋남은 상단에 집중돼 있습니다:

```
2023  bin 17  pred 0.5563  actual 0.5320  gap −0.0243
      bin 18  pred 0.5726  actual 0.5466  gap −0.0260
      bin 19  pred 0.6040  actual 0.5386  gap −0.0654   <-- 극단
```

즉 2023에서 v9는 **자신 있는 예측을 과신**했습니다. 2024에는 이 패턴이 없습니다
(bin 19 gap **+0.0046**).

## 4. 왜 전이되지 않는가 — 부호가 뒤집힙니다

두 시즌의 구간별 gap을 직접 대조했습니다.

```
부호 일치       4 / 20 bin
gap 상관계수    −0.6049          <-- 음의 상관
2023 gap 평균  −0.00113  sd 0.01860
2024 gap 평균  −0.00602  sd 0.00639
```

| bin | 2023 gap | 2024 gap |
|---|---|---|
| 0 | **+0.0122** | **−0.0092** |
| 5 | **+0.0101** | **−0.0033** |
| 11 | **+0.0154** | **−0.0045** |
| 19 | **−0.0654** | **+0.0046** |

**두 시즌의 miscalibration은 음의 상관(−0.60)입니다.** 2023에서 과소예측한 구간을
2024에서는 과대예측합니다. 2023에서 배운 보정은 2024를 **정확히 반대 방향으로**
밀어냅니다.

적합된 파라미터가 이를 그대로 보여줍니다.

```
2023 에서 적합한 temperature   a = 0.718     (예측을 0.5 쪽으로 크게 축소)
2024 에서 적합한 temperature   a = 1.083     (오히려 확대)
```

**a < 1과 a > 1**, 방향이 반대입니다. 2023용 축소(a=0.718)를 2024에 적용하면
Reliability가 42.9 → **149.4**로 3.5배 악화됩니다.

## 6. 이 결과가 기존 결론에 더하는 것

12~14차가 "calibration/post-processing은 Resolution을 못 올린다"고 결론지었고
`r2_decomp.py`가 "Reliability가 작으면 남은 점수는 전부 Resolution에서 와야
한다"고 적었습니다. 이 감사가 두 가지를 보탭니다.

1. **Resolution 불변은 경험적 관찰이 아니라 정리입니다.** 분위 구간 기반 분해에서
   단조 변환은 Resolution을 정확히 보존합니다. 어떤 calibration 방법을 더
   시도해도 결과는 같습니다. **이 방향은 닫혔습니다.**
2. **Reliability는 작지 않은데도 접근 불가입니다.** 2023의 155.0은 큰 값이고
   isotonic이 in-sample로 전부 회수합니다. 그러나 시즌 간 gap 상관이 **−0.60**
   이라 전이가 불가능합니다. "회수할 것이 없다"가 아니라 **"회수할 것은 있는데
   그것이 시즌마다 다른 것"** 입니다.

이는 C-2·G0·pitcher×batter가 도달한 결론과 같은 구조입니다 — 정보는 시즌 내에
존재하고, 시즌 경계를 넘지 못합니다.
