## 0. 이 실험이 묻는 것

새 feature를 만드는 게 목적이 아닙니다. 질문은 하나입니다.

> **v9가 놓친 pitcher-batter interaction 정보가 실제로 존재하며, 2025 test에
> 배포 가능한 형태로 전이되는가?**

16차 `d2_forward`가 46개 조건 중 **두 시즌 모두 양수인 유일한 항목**으로 이것을
남겼습니다 (2023 **+0.47 ± 0.95**, 2024 **+2.29 ± 1.12**). 크기는 작지만 부호가
일관된 유일한 후보이므로, 왜 작은지를 규명하고 개선 여지가 있는지 확인합니다.

## 1. 16차가 실제로 한 것과 하지 않은 것

`work/research/resolution_discovery/d2_forward.py`를 읽고 확인했습니다.

```python
dtr = tr.control_success - tr.p_v9;  dtr -= dtr.mean()      # 잔차, 중심화
g   = groupby(cell).agg(n, m=mean(dtr))
off = cva.map(g.m * g.n / (g.n + k)).fillna(0.0)            # 축소 + 미관측은 0
p1  = clip(p0 + off, .001, .999)                            # 확률 공간 가산
best = argmax_k BSS(p1)                                     # k 를 검증 시즌에서 선택
```

| 검토 항목 | 16차 | 상태 |
|---|---|---|
| 1. raw aggregate | k=10 이 사실상 raw에 근접 | **구현됨** |
| 2. Bayesian shrinkage | `n/(n+k)`, k ∈ {10,30,100,300,1000} | **구현됨** (단순형) |
| 3. hierarchical fallback | 미관측 셀 → **offset 0** | **미구현** |
| 4. year decay weighting | 시즌 가중 없음, 5시즌 균등 | **미구현** |
| 5. sample confidence feature | `n`은 축소식 안에만, 모델에 노출 안 됨 | **미구현** |

추가로 두 가지 방법론 문제가 있습니다.

**(a) k를 검증 시즌에서 골랐습니다.** `best = argmax_k BSS(p1)`이 2024에서 최적
k를 선택합니다. 보고된 **+2.29는 낙관 편향**이며, 정직한 값은 더 낮습니다.

**(b) 모델 feature가 아니라 사후 가산 offset입니다.** `p0 + off`는 모든 행에
같은 신뢰도를 강제합니다. feature로 넣으면 트리가 "n이 작을 때는 무시"를 스스로
학습할 수 있는데, 그 여지가 없었습니다.

**이 실험의 실질 내용은 3·4·5 + (a)(b) 보정입니다.**

## 2. 데이터 실측 — 설계를 지배하는 숫자

fold 2024 (train 2019–2023 1,221,585행 → valid 2024 253,507행) 기준.

### 2.1 셀 희소성

```
고유 (P,B) 페어      82,297
페어당 투구수         중앙값  9    평균 14.8   최대 250
                     25%  5 · 75% 18 · 90% 34 · 99% 95
n>=10 페어           38,373 (46.6%)
n>=30 페어           10,193 (12.4%)
```

### 2.2 커버리지 — **가장 중요한 숫자**

```
2024 행 중 과거에 본 페어      51.2%   (129,691 행)
              처음 보는 페어   48.8%   (123,816 행)   <-- 16차는 여기에 offset 0
  과거 n>=  5 인 행            46.2%
  과거 n>= 10 인 행            37.6%
  과거 n>= 30 인 행            18.5%
  과거 n>=100 인 행             2.6%
본 페어의 과거 n 중앙값          20
```

**16차의 +2.29는 절반(51.2%)의 행에서만 나온 값입니다.** 나머지 48.8%는 offset이
정확히 0이었습니다. 그리고 관측된 절반조차 행별 n 중앙값이 2에 불과합니다.

### 2.3 계층 fallback 여지

| 단계 | 셀 수 | 행 커버리지 | 행별 n 중앙값 |
|---|---|---|---|
| **L1** P × B | 82,297 | **51.2%** | 2 |
| **L2** P × Bhand | 1,413 | **80.1%** | 1,159 |
| **L3** P | 711 | **80.1%** | 2,400 |

L2/L3가 80.1%에서 멈추는 이유는 2024 신규 투수(81명, 행의 19.9%)입니다. L1의
51.2% → L2의 80.1%로 **29%p를 회수**할 수 있습니다.

> 다만 L2(P × 타자손)와 L3(P)는 **v9가 이미 쓰고 있습니다** — `edge_bh`가 P×Bhand,
> `carry_p_*`/`asof_pitcher_*`가 P입니다. 따라서 fallback은 새 정보를 주는 게
> 아니라 **L1의 결측을 v9가 이미 아는 값으로 메우는 것**이며, 순 기여는
> L1 관측 구간에서만 발생합니다. 이 점이 기대값을 크게 제약합니다.

### 2.4 year decay 근거

시즌별 페어가 2024에도 등장하는 비율:

```
2019  12.1%     2020  14.7%     2021  17.6%     2022  23.3%     2023  33.3%
```

최신 시즌일수록 재출현율이 **2.75배** 높습니다. 균등 가중은 오래된, 다시 만나지
않을 매치업에 같은 무게를 줍니다. 지수감쇠의 근거가 있습니다.

## 4. 설계 — 5개 검토 항목

### 4.1 타깃

v9 잔차를 로짓 공간에서 정의합니다. 16차는 확률 공간(`y − p_v9`)이었는데,
v9 자체가 `sigmoid(init + shape)` 구조이므로 로짓이 일관됩니다.

```
r_i = logit(y_i 를 향한 방향) 대신 실무적으로:
r_i = y_i − p_v9,i           (16차와 동일, 비교 가능성 유지)
z_i = logit(p_v9,i) 기준 편차  (대안, 부수 측정)
```

주 실험은 16차와 비교 가능하도록 `r_i`를 쓰고, `z_i`는 부수 보고합니다.

### 4.2 항목 1·2 — raw aggregate + Bayesian shrinkage

셀 `c = (pitcher_id, batter_id)`에 대해

```
m_c = Σ w_i r_i / Σ w_i          (가중 평균, w 는 4.4 의 decay)
n_c = Σ w_i                       (유효 표본수)
offset_c = m_c · n_c / (n_c + K)  (경험적 베이즈 축소)
```

**K는 2023 fold에서 고릅니다** (train 2019–2022 → valid 2023). 2024는 최종 평가
한 번만 봅니다. 16차의 (a) 문제를 이렇게 제거합니다.

K 후보: {10, 30, 100, 300, 1000, 3000}. 실측 n 중앙값이 9이므로 K가 30만 되어도
축소율이 0.23입니다 — **K를 크게 올리면 신호가 거의 사라집니다.** 이 긴장이
이 실험의 핵심 난점이고, 그래서 4.5의 confidence feature가 필요합니다.

### 4.3 항목 3 — hierarchical fallback

미관측 셀을 0이 아니라 상위 계층으로 후퇴시킵니다.

```
offset(row) = α1·off_L1 + (1−α1)·[ α2·off_L2 + (1−α2)·off_L3 ]
  α1 = n_L1 / (n_L1 + K1)
  α2 = n_L2 / (n_L2 + K2)
```

L1이 두터우면 L1을, 얇으면 L2(P×Bhand), 그것도 없으면 L3(P)로 자연스럽게
이동합니다. **주의**: L2·L3는 v9가 이미 쓰므로 이 항이 순 기여를 만들지는
않습니다. 목적은 "L1 결측 구간에서 0을 강제하지 않는 것"이며, **L1 단독 대비
개선이 없다면 fallback은 기각**합니다. 그것이 fallback의 게이트입니다.

### 4.4 항목 4 — year decay weighting

```
w_i = exp( −(S_target − 1 − season_i) / τ )
```

τ 후보: {∞(균등, 16차), 3.0, 1.5, 0.8}. 재출현율(12.1→33.3%)이 시즌당 약 1.3배
증가하므로 τ ≈ 1/ln(1.3) ≈ 3.8이 데이터가 시사하는 값입니다. τ는 **2023 fold에서
선택**합니다.

decay는 `n_c`도 줄이므로 축소가 강해집니다. K와 τ를 **함께** 그리드로 봅니다.

### 4.5 항목 5 — sample confidence feature

16차가 `n`을 축소식 안에만 썼습니다. 모델에 노출하면 트리가 조건부 신뢰도를
학습할 수 있습니다. 노출할 컬럼:

| feature | 의미 |
|---|---|
| `pxb_offset` | 4.3의 계층 offset |
| `pxb_n_raw` | L1 원시 관측 수 (log1p) |
| `pxb_n_eff` | decay 적용 유효 표본수 (log1p) |
| `pxb_alpha1` | L1 축소 계수 = 신뢰도 |
| `pxb_seen` | L1 관측 여부 이진 (0/1) — **48.8%가 0** |
| `pxb_last_season` | 그 페어를 마지막으로 본 시즌 (없으면 결측) |

`pxb_seen`은 특히 중요합니다. 절반의 행에서 offset이 무의미하다는 사실을
모델에게 **명시적으로** 알려 줍니다.

## 5. 검증 설계

### 5.1 두 갈래 평가 — 둘 다 보고

| | 방식 | 목적 |
|---|---|---|
| **M1 offset** | `p = clip(p_v9 + offset, ...)` | 16차와 **직접 비교 가능** |
| **M2 feature** | v9 feats 101 + pxb 6개 → LightGBM, `init`을 init_score | 조건부 신뢰도 학습 여지 |

M2는 A(v9만) / B(v9+pxb) 쌍으로 돌려 **B−A**를 봅니다. G0에서 확립한 규율입니다 —
B를 p_v9에 직접 대면 모델 적합 이점이 섞입니다.

### 5.2 temporal split

```
하이퍼파라미터 선택   train 2019–2022  →  valid 2023      (K, τ, K1, K2)
최종 평가            train 2019–2023  →  valid 2024      (한 번만)
```

**2024에서 어떤 것도 고르지 않습니다.** 16차의 낙관 편향을 제거하는 핵심입니다.

### 5.3 3 seed

M1은 결정론적(닫힌 형식 집계)이라 seed 개념이 없습니다. **M2의 LightGBM만
seed 42/43/44**로 돌리고 평균 ± 표준편차를 보고합니다. G0에서 basic seed42가
+16.3, seed44가 −4.4로 부호가 뒤집힌 전례가 있으므로 단일 seed 판정은 하지
않습니다.

M1의 불확실성은 seed가 아니라 **paired bootstrap**(B=200)으로 잽니다.

### 5.4 보고 항목

- dResolution, dBSS, paired ± se, σ
- **`pxb_seen=1` / `=0` 부분집합 분리 보고** — 51.2% / 48.8%
- 4단계 ablation: L1만 / L1+shrink / +fallback / +decay / +confidence
- M2의 feature importance에서 pxb 6개의 gain 점유율

### 5.5 v9 baseline

fold 2024: `p_v9` BSS 917.2 / Res 960.3 / Rel 42.9
fold 2023: `p_v9` BSS 403.1 / Res 558.7 / Rel 155.0

## 6. 게이트

```
PASS:  3-seed 평균 dRes >= +10  AND  dBSS > 0  AND  paired >= 2 sigma
       (2024 에서, 하이퍼파라미터는 2023 에서 고정한 채)
FAIL:  그 외
```

프로젝트 STRONG 기준은 +20이지만, 이 후보는 애초에 +2 수준에서 출발하므로
**+10을 채택 검토선**으로 둡니다. 그 아래면 배포 이득이 없습니다.

**중간 중단 조건**: 2023 fold(하이퍼파라미터 선택 단계)에서 최적 설정의
dBSS가 음수이면 2024를 열지 않고 중단합니다.

## 7. 예상 결과

| 시나리오 | 2024 dRes | 확률 |
|---|---|---|
| 16차 재현 수준 (+1 ~ +3) | | **~55%** |
| 개선되나 미달 (+3 ~ +10) | | ~30% |
| PASS (+10 이상) | | **~12%** |
| 음수 (k 선택 편향 제거 효과) | | ~3% |

**근거**

- 16차 +2.29는 검증 시즌에서 k를 골라 얻은 값입니다. 편향 제거만으로 **하락**합니다.
- fallback이 회수하는 29%p 구간은 L2/L3인데 **v9가 이미 쓰는 정보**입니다.
  순 기여는 L1 관측 구간(51.2%)에 한정됩니다.
- 그 51.2%조차 행별 n 중앙값이 2입니다. K=30만 되어도 축소율 0.06입니다.
- decay와 confidence feature는 방법론적으로 옳지만, 없는 신호를 만들지는 못합니다.

**가장 큰 상승 여지**는 confidence feature입니다. 모델이 "n≥30인 18.5% 행에서만
offset을 신뢰"를 학습하면, 그 구간에서 축소를 약하게 가져갈 수 있습니다. 16차는
전 행에 같은 축소를 강제했으므로 여기가 실질적 미탐색 영역입니다.
