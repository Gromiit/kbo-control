## 0. 한 줄 요약

**v9는 특정 유형에서 실패하지 않습니다. 거의 모든 곳에서 아주 조금씩, 같은
방향으로 과대예측합니다.**

가장 큰 단일 체계적 편향이 **−0.0149**(좌투수-좌타자)이고, 전체 편향은

예외는 하나 — **투수 개인 수준의 편차가 우연보다 15배 많습니다**(|z|≥3인 투수
11명, 기대 0.7명). 그러나 이는 이미 v9가 접근할 수 없다고 확인된 정보입니다.

## 1. 전체 분해

```

2023   n 245,525   BSS 403.1   Res 558.7   Rel 155.0                        (BCAT 붕괴 fold)
```

**Reliability 42.9는 BSS 917.2의 4.7%입니다.** 즉 v9의 점수 손실은 캘리브레이션이
아니라 **Resolution 부족**, 곧 판별력의 한계에서 옵니다. AUC 0.556, 예측 범위

전역 편향 +0.0060은 v9가 **평균적으로 약간 낙관적**(성공률을 과대예측)이라는
뜻이고, 아래 모든 분할에서 같은 방향이 반복됩니다.

## 3. 분할변수별 — 어떤 변수도 두드러지지 않습니다

19개 분할변수의 Reliability 기여 합계 (`n≥200` 그룹만):

| 변수 | 그룹 | Rel기여합 | \|z\|≥3 | 최대 \|gap\| |
|---|---|---|---|---|
| B team | 12 | 38.6 | 6 | 0.0139 |
| count | 12 | 25.6 | 4 | 0.0162 |
| P team | 12 | 21.4 | 2 | 0.0146 |
| B asof_n | 10 | 21.1 | 2 | 0.0124 |
| P succ rate | 10 | 20.8 | 2 | 0.0131 |
| month | 8 | 20.5 | 2 | 0.0211 |
| hand pair | 4 | 20.2 | 3 | 0.0149 |
| … (나머지 12개 변수 14.5 ~ 20.0) | | | | |

**전 변수가 14.5~38.6 범위에 몰려 있습니다.** 어떤 변수도 다른 것보다 두 배 이상
설명하지 못합니다. 이는 특정 축에 구조적 결함이 있는 것이 아니라, **어느 축으로
잘라도 같은 전역 편향(−0.006)이 다시 보이는 것**입니다.

### 상위 15 그룹 (|z|≥3)

```
game_type    R      223,497   pred 0.4962  actual 0.4897   gap -0.0065  z -6.1
runners      0      131,633   pred 0.4921  actual 0.4843   gap -0.0078  z -5.7
B hand       1      119,761   pred 0.4948  actual 0.4869   gap -0.0079  z -5.5
hand pair    1x1     30,493   pred 0.4688  actual 0.4538   gap -0.0149  z -5.2
P hand       2      181,677   pred 0.4925  actual 0.4868   gap -0.0057  z -4.9
month        7       33,070   pred 0.4919  actual 0.4799   gap -0.0120  z -4.4
count        0-0     65,317   pred 0.4948  actual 0.4863   gap -0.0085  z -4.3
P succ rate  최하위   25,344   pred 0.4401  actual 0.4271   gap -0.0131  z -4.2
```

**주목할 점 두 가지.**

1. **`game_type=R`이 1위인데 n이 223,497로 전체의 88%입니다.** z가 큰 이유는
   gap이 커서가 아니라 표본이 커서입니다(gap −0.0065 = 전역 편향과 사실상 동일).
   `runners=0`, `B hand=1`, `P hand=2`도 마찬가지 — **전부 큰 다수 그룹이며
   gap이 전역 편향을 그대로 반영**합니다. 즉 "이 그룹이 특별히 틀린다"가 아니라
   "전역 편향이 통계적으로 검출될 만큼 표본이 크다"입니다.

2. **진짜 국소 편향은 `hand pair 1x1` 하나**입니다 — gap **−0.0149**로 전역
   편향의 2.5배이고 n 30,493(12%)로 부분집합입니다. 좌투수-좌타자 대결에서 v9가
   1.5%p 과대예측합니다. 그러나 **v9는 이미 `same_hand` feature와
   `edge_bh`/`pph` 조건부 테이블을 가지고 있습니다.** 남은 1.5%p는 그 위의
   잔차입니다.

## 5. 고확신 구간 — 실패하지 않습니다

```
  |p-.5| < 0.02  (무확신)     n  87,293 (34.4%)  방향적중 50.8%   BSS     0.0
  0.02 ~ 0.05                n  95,547 (37.7%)  방향적중 53.6%   BSS   473.3
  0.05 ~ 0.08                n  47,529 (18.7%)  방향적중 57.1%   BSS  1803.7
  |p-.5| >= 0.08 (고확신)     n  23,138 ( 9.1%)  방향적중 60.5%   BSS  4359.3
```

**확신이 높을수록 정확합니다.** 방향적중률이 50.8% → 60.5%로 단조 증가하고,
BSS는 0.0 → 4359.3으로 올라갑니다. gap도 −0.0089 → **−0.0027**로 오히려
줄어듭니다.

**고확신 구간의 과신은 없습니다.** (2023 BCAT의 상위 bin 붕괴와 대조되며,
그것이 BCAT 고유 문제였다는 Stage 0 판정과 일치합니다.)

### 고확신인데 틀린 9,142행 (39.5%)의 성격

```
                             맞은쪽 중앙    틀린쪽 중앙
  asof_pitcher_n              2,517.5       2,610.5

  li                              0.800         0.800
```

**구분되는 특징이 하나도 없습니다.** 표본 수, 레버리지, 이닝, 성공률 모두
사실상 동일합니다. 고확신 오분류는 **식별 가능한 하위 유형이 아니라 잔여
확률성**입니다.

## 6. 결론 — 어떤 유형에서 체계적으로 실패하는가

### 답 1: 전역적 소폭 과대예측 (+0.0060)

어느 축으로 잘라도 같은 −0.006 편향이 재등장합니다. 상위 그룹 목록이 전부
"큰 다수 그룹"인 것이 그 증거입니다. **이것은 국소 결함이 아니라 레벨 문제**이고,
상수 보정은 시즌 간 전이가 안 됩니다(calibration 감사).

### 답 2: 좌투수 대 좌타자 (gap −0.0149, n 30,493)

전역 편향의 2.5배로 유일하게 두드러지는 국소 편향입니다. v9가 `same_hand`와
`edge_bh`/`pph`를 이미 쓰고 있으므로 **남은 것은 그 위의 잔차 1.5%p**입니다.
16차 d2가 `PxB hand x count`를 −5.9/−5.5로, `P x Bhand`를 −27.2/−24.1로
측정했으므로 이 축의 추가 조건화는 이미 기각됐습니다.

### 답 3: 투수 개인 (|z|≥3 11명, 기대의 15.7배) — **진짜 답이지만 접근 불가**

유일하게 우연을 크게 넘는 축이며, 개별 gap이 최대 ±0.10입니다. 그리고 이
정보를 쓰려는 다섯 번의 시도가 모두 실패했습니다(§4 표).

### 답 4: 고확신 구간은 실패하지 않음

확신이 높을수록 정확하고, 틀린 표본에 식별 가능한 특징이 없습니다.

## 7. 이 분석이 함의하는 것

**"v9가 어디서 틀리는지"에 대한 답은 "특별히 어디랄 것 없이, 투수 개인 수준에서
조금씩"입니다.** 그리고 투수 개인 수준 정보는 이 프로젝트가 다섯 갈래로
접근을 시도해 전부 막힌 지점입니다.

새 feature나 새 모델을 제안하지 않습니다 — 이 분석의 결론은 **v9의 남은 오차가
구조적 결함이 아니라 (a) 전이되지 않는 레벨 편향과 (b) 규정상 접근 불가한 투수
상태로 구성돼 있다**는 것입니다.
