## 0. 착수 전 발견 — 2023 fold의 BCAT가 깨져 있습니다

게이트 임계값을 검증하려고 구성요소별 단독 성능을 재다가 확인했습니다.

```
=== 2023 ===
  p_A7      BSS   821.5   Res  844.5   Rel    21.1
  p_A9      BSS   843.8   Res  893.9   Rel    48.5
  p_Bcat    BSS     0.0   Res  523.1   Rel  1777.6     <-- 붕괴
  v9 (3요소) BSS   403.1                                <-- A9 단독보다 나쁨

=== 2024 ===
  p_A7      BSS   808.6   Res  873.6   Rel    72.8
  p_A9      BSS   829.4   Res  880.3   Rel    53.2
  p_Bcat    BSS   827.3   Res  856.1   Rel    28.2
  v9 (3요소) BSS   917.2                                <-- 최고 단독 대비 +88
```

**2023에서 BCAT의 Reliability가 1777.6입니다.** Resolution은 523.1로 정상 범위인데
캘리브레이션이 완전히 어긋나 BSS가 0으로 클리핑됐습니다. 그 결과 0.45 가중을
받은 BCAT가 앙상블을 끌어내려, **v9(403.1)가 A9 단독(843.8)보다 나쁩니다.**

2024에서는 세 요소가 모두 건강하고 블렌드가 최고 단독보다 +88 앞섭니다.

### 이 발견이 E0에 미치는 영향

1. **2023은 앙상블 선택 fold로 쓸 수 없습니다.** 그 시즌 최적해는 "BCAT를 빼라"인데
   그건 BCAT 결함을 고치는 것이지 일반화되는 신호가 아닙니다. 앞서 측정한
   가중치 전이 −79.0, stacking 전이 −154.3이 전부 이 결함의 결과입니다.
2. **상관 구조도 2023에서는 무의미합니다.** 2023 평균 쌍상관 0.538은 다양성이
   아니라 BCAT가 망가져서 생긴 값입니다. **E0의 상관 판정은 2024에서만 합니다.**
3. 계획서(`experiments/ensemble/PLAN.md`) §2의 "결합 최적화 여지 없음" 결론은
   유지됩니다 — 2024 in-sample 최적 가중이 현재 값과 +0.4 차이입니다.

> 이 결함은 **보고 대상이지 수정 대상이 아닙니다.** `submit_v9.zip`은 고정이고,
> 제출은 2025 평가이며 2024에서 BCAT는 정상입니다.

## 1. 게이트 임계값 — 조정을 제안합니다

주신 기준: PASS `평균 상관 < 0.85`, FAIL `≥ 0.90`. **0.85~0.90 구간이 비어 있고**,
더 중요하게는 **기존 구성요소들이 그 기준을 통과하지 못합니다.**

2024 로짓 상관:

| 구성요소 | 나머지 둘과의 평균 상관 |
|---|---|
| p_Bcat | **0.8187** |
| p_A7 | 0.8875 |
| p_A9 | 0.8960 |
| **전체 쌍 평균** | **0.8674** |

가중치 0.45로 가장 중요하고 stacking 계수도 가장 큰(0.477) **BCAT조차 0.819**입니다.
신규 모델에 `< 0.85`를 요구하면 **기존 최우수 구성요소보다 엄격한 기준**이 됩니다.

**제안: 절대값이 아니라 기존 대비 상대 기준으로 판정합니다.**

| 구간 | 판정 |
|---|---|
| 평균 상관 **≤ 0.82** | **PASS** — BCAT 수준의 다양성. 명확히 추가적 |
| 0.82 ~ 0.90 | **보류** — 상관만으로 결정 불가. §4의 blend 상한으로 판정 |
| **≥ 0.90** | **FAIL** — A9(0.896)보다도 중복. 즉시 중단 |

주신 FAIL 기준(≥ 0.90)은 그대로 두고, PASS 기준만 0.85 → 0.82로 낮추며 중간
구간의 처리를 명시했습니다. 승인해 주시면 이대로 진행합니다.

## 3. XGBoost OOF 생성

### 3.1 데이터 규율

```
fold S ∈ {2023, 2024}
  학습   data/folds/fold_S_tr.parquet   (시즌 < S)
  검증   data/folds/fold_S_va.parquet   (시즌 = S, p_v9 포함)
  feature  v9 numeric_feats 101  (dataset.feature_cols(), import 재사용)
  init     level logreg log-odds
```

- **test.csv를 열지 않습니다.** 코드에 경로가 등장하지 않습니다.
- 시즌 S 행은 학습에 들어가지 않습니다. 기존 fold parquet이 이미 보장합니다.
- carry/split/role/lowrank 테이블은 fold 생성 시점에 시즌<S로 동결된 것을 그대로
  씁니다. 재적합하지 않습니다.

### 3.2 두 개의 arm — 다양성이 목적이므로

| arm | init 처리 | 의도 |
|---|---|---|
| **base** | `base_margin = init` (v9 A계열과 동일) | 공정 비교. 상관이 높게 나올 가능성 |
| **noinit** | init 미사용, 라벨 직접 학습 | **다양성 최대화.** 레벨은 어긋나지만 오류 구조가 달라질 여지 |

`noinit`을 넣는 이유는 E0가 성능이 아니라 **다양성**을 재기 때문입니다. init을
공유하면 예측이 구조적으로 붙습니다. 단독 BSS는 낮게 나오겠지만 상관이 낮다면
blend에서 기여할 수 있고, 그 판정은 §4가 합니다.

### 3.3 파라미터

```
tree_method  hist
max_depth    6
eta          0.05
subsample    0.8
colsample_bytree  0.7
lambda       10.0
min_child_weight  200
num_boost_round   2000,  early_stopping 100 (검증 fold 기준)
seed         42, 43, 44
```

LightGBM 대비 의도적으로 다르게 둔 것은 없습니다. **다른 라이브러리라는 사실
자체**(결측 처리·분할 규칙·정규화가 다름)가 다양성의 원천이고, 파라미터를
억지로 비틀면 단순히 나쁜 모델이 됩니다.

seed 3개는 seed 평균 예측 하나를 만들기 위한 것입니다(v9의 raw-score 평균과
동일 방식). 게이트 판정은 seed 평균으로 하되 seed별 분산도 보고합니다.

## 4. 평가

### 4.1 단독 성능

2024에서 XGB seed 평균의 BSS / Resolution / Reliability. 참조:

```
p_A7 808.6   p_A9 829.4   p_Bcat 827.3   v9 블렌드 917.2
```

"허용 범위"의 조작적 정의: **base arm이 BSS ≥ 750** (최저 구성요소 808.6의 약 93%).
이보다 낮으면 모델이 잘못 학습된 것이지 다양성이 아닙니다. `noinit` arm은
레벨이 어긋나므로 이 기준을 적용하지 않고 상관과 blend 기여로만 판정합니다.

### 4.2 상관 (게이트 주 지표)

로짓 공간에서 XGB와 A7 / A9 / BCAT 각각의 상관, 그리고 평균. **2024 기준.**
2023 값도 계산하되 §0의 이유로 판정에는 쓰지 않습니다.

### 4.3 blend 상한 개선 가능성

기존 3요소 로짓 stacking의 2024 in-sample 상한이 **+19.4 ± 5.4**입니다(측정 완료).
XGB를 넣은 4요소로 같은 계산을 합니다.

> **주의: 이것은 상한이지 결과가 아닙니다.** 2024를 보고 맞춘 값이므로 배포
> 가능성 주장이 아닙니다. E0는 "여지가 있는가"만 묻고, 실제 전이 검증은 E2가
> 합니다. 3요소 +19.4 대비 **+10 이상** 개선되지 않으면 E1로 넘어가지 않습니다.

### 4.4 게이트

```
PASS   평균 상관(2024) ≤ 0.82
       AND base arm BSS ≥ 750
       AND 4요소 stacking 상한 ≥ 3요소 상한 + 10   (즉 ≥ +29.4)

보류   평균 상관 0.82 ~ 0.90  →  상한 조건만으로 판정

FAIL   평균 상관 ≥ 0.90
       OR  상한 개선 < +10
```

FAIL이면 E1/E2를 구현하지 않고 앙상블 라인을 종료합니다.

## 5. 예상

| 결과 | 확률 |
|---|---|
| 상관 ≥ 0.90 → FAIL | **~55%** |
| 0.82~0.90, 상한 개선 부족 → FAIL | ~30% |
| PASS | **~15%** |

`base` arm은 같은 feature 101개 + 같은 init을 쓰므로 A7/A9와 0.93 이상이 나올
것으로 봅니다. 희망은 `noinit` arm 쪽인데, 그건 단독 성능을 크게 잃습니다.

기존 3요소 stacking 상한이 +19.4라는 점이 근본 제약입니다. 이는 **2024를 보고
맞춘 완벽한 stacker**의 값이고, 프로젝트 STRONG 기준(+20)에도 못 미칩니다.
4번째 모델이 이 상한을 +29.4 위로 밀어 올리려면 기존 셋과 실질적으로 다른
오류 구조를 가져야 합니다.

## 8. 승인이 필요한 항목

1. **게이트 PASS 임계값 0.85 → 0.82** (§1). 기존 최우수 구성요소 BCAT가 0.819라
   0.85로는 기존 모델도 통과하지 못합니다.
2. **`noinit` arm 포함 여부** (§3.2). 다양성 측정에 유용하나 학습 6회가 늘어납니다.

   신뢰 불가입니다.

승인해 주시면 `build_xgb_oof.py` / `e0_diversity.py`를 작성해 실행하겠습니다.
