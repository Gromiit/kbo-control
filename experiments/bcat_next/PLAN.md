# BCAT 개선 가능성 검토 — E0 계획

## 0. 착수 전 진단 — 개선 지점이 정확히 특정됩니다

계획을 쓰기 전에 기존 OOF만으로 BCAT를 분해했습니다. 학습은 하지 않았습니다.

### 0.1 2023 붕괴는 전면적이 아니라 **상위 2개 bin에 집중**돼 있습니다

`p_Bcat` 2023, 20분위 reliability 분해 (Reliability 총 1777.6):

```
   bin      n     pred   actual      gap   Rel기여
     0  12,277   0.4061   0.4326  +0.0265      14.1
     ...  (bin 1~17 은 gap +0.002 ~ +0.027, 기여 15 미만)
    17  12,276   0.5711   0.5699  -0.0012       0.0
    18  12,276   0.6547   0.4520  -0.2027     821.5   <-- 
    19  12,277   0.7054   0.4990  -0.2064     852.3   <-- 
   상위 3 bin 이 Rel 의 95.0% 차지
```

**상위 10%에서 0.65~0.71을 예측했는데 실제는 0.45~0.50, 즉 기저율입니다.**
자신 있게 낸 예측이 정보가 아니라 잡음이었습니다. bin 0~17은 정상입니다.

2024에는 이 병리가 없습니다 (최대 gap 0.0147, Rel 총 28.2).

```
        p_Bcat sd    95분위    Rel
  2023    0.0698    0.680    1777.6
  2024    0.0459    0.571      28.2
```

전역 편향은 두 시즌 모두 작습니다(+0.008, +0.002). **레벨 문제가 아니라 상단
꼬리 문제입니다.**

### 0.2 구조적 용의자

```
b_feats 68개   b_cat_features ['pitcher_team_id','batter_team_id','count_state','base_state_c']
b_with_ids True   -> pitcher_id_num, batter_id_num 포함
모델 2개 (cat_0, cat_1)   vs A7/A9 각 12 booster
```

**BCAT만 엔티티 ID를 직접 씁니다.** CatBoost의 target statistic 처리와 결합하면
특정 투수/타자에 대해 극단적 확신을 낼 수 있고, 그것이 홀드아웃에서 무너지는
것이 정확히 관측된 패턴입니다. 게다가 **평균 모델이 2개뿐**이라(A7/A9는 12개)
분산 억제가 가장 약합니다.

이건 가설이며 §3의 E0가 검증할 대상입니다.

### 0.3 그런데 목표 시즌(2024)에서의 상한은 작습니다

```
BCAT 를 2024 에서 isotonic 으로 완벽 교정 (in-sample, 배포 불가):
  BCAT 단독   BSS 827.3 -> 868.2   (+40.9)
  v9 블렌드   BSS 917.2 -> 942.8   dBSS +25.6 ± 2.4
```

**2024에서 BCAT를 완벽하게 고쳐도 블렌드 이득의 상한은 +25.6입니다.** 그리고
이건 2024를 보고 맞춘 값이라 배포 가능성 주장이 아닙니다.

## 1. 그래서 이 검토가 묻는 것

두 가지가 뒤섞이면 안 됩니다.

| | 질문 | 상태 |
|---|---|---|
| **점수** | 2024 BSS를 올릴 수 있는가 | 상한 **+25.6** (in-sample). 앞선 calibration 감사가 보였듯 교정은 시즌 간 전이가 안 됨 |
| **리스크** | 2025에 2023 같은 붕괴가 재발하는가 | **미지수.** BCAT는 weight 0.45 |

점수 쪽은 기대가 낮습니다. **리스크 쪽이 이 검토의 실질 가치**입니다 — 2023에
한 번 일어난 일이 2025에 일어나면 제출본이 크게 손해를 봅니다.

다만 요청하신 게이트는 점수 기준이므로 그대로 적용하고, 리스크 관련 관찰은
별도로 기록합니다.

## 2. E0 게이트 (주신 기준 그대로)

```
E0-1  단독 BSS >= 기존 BCAT (2024 기준 827.3)
E0-2  A7/A9 대비 correlation <= 0.85
E0-3  stacking upper bound +10 이상 가능성

하나라도 실패하면 학습 추가 금지.
```

**참조값** (2024, 로짓 상관):

```
기존 BCAT   vs A7 0.8102   vs A9 0.8273        <-- 이미 <= 0.85 통과
3요소 stacking in-sample 상한  +19.4
```

E0-2는 기존 BCAT가 이미 만족합니다. 즉 **variant가 이 성질을 잃지 않으면 됩니다.**
ID feature를 빼는 등의 변경이 오히려 A계열과 비슷하게 만들 수 있으므로 확인이
필요합니다.

E0-3의 "+10 이상"은 3요소 상한 +19.4 대비 **+29.4 이상**으로 읽습니다.

## 3. E0 실행 설계 — 학습 없이 시작합니다

주신 조건이 "빠르게 판단"이므로, **모델을 새로 학습하기 전에 기존 OOF만으로
답할 수 있는 것을 먼저 답합니다.**

### 3.1 Stage 0 — 무학습 진단 (30분, 코드 소량)

기존 `oof_{2023,2024}.parquet`만 사용합니다.

| 항목 | 목적 |
|---|---|
| A. 2023 bin18/19 행의 특성 프로파일 | 그 10%가 어떤 행인가 — 특정 투수/타자에 몰려 있는가, `asof_n`이 작은가, 팀·카운트 편중이 있는가 |
| B. 같은 행의 A7/A9 예측 | A계열은 정상인가. 정상이면 BCAT 고유 문제로 확정 |
| C. 2024에서 같은 프로파일 행의 BCAT | 병리가 잠재해 있는가, 아니면 2023 고유인가 |
| D. shift(−0.04) 제거·조정 시 2023/2024 Rel | 상수 하나로 완화되는가 |
| E. 상단 꼬리 클리핑(p ≤ 0.60 등) 감도 | 가장 값싼 완화책의 효과 |

**Stage 0에서 "2023 고유 사고"로 판명되면 여기서 종료합니다.** 재발 위험이 없고
2024 상한이 +25.6이므로 학습할 이유가 없습니다.

**"구조적 병리"로 판명되면** Stage 1로 갑니다.

### 3.2 Stage 1 — variant 학습 (Stage 0 통과 시에만)

CatBoost variant를 fold 2023·2024에서 walk-forward로 학습해 OOF를 만들고 E0
게이트를 적용합니다. 후보 축은 §0.2의 용의자에 대응합니다.

| variant | 변경 | 가설 |
|---|---|---|
| `noid` | `pitcher_id_num` / `batter_id_num` 제거 | ID 기억이 원인 |
| `seed6` | 모델 2개 → 6개 seed 평균 | 분산 억제 부족이 원인 |
| `depth` | depth 축소 + l2 강화 | 과적합이 원인 |

각 variant에 seed 3개, 두 fold. `b_feats` 68개와 `b_cat_features` 4개는 그대로
씁니다(입력 공간을 바꾸면 다른 실험이 됩니다).

**판정은 2024로 합니다.** 2023은 §0.1의 붕괴 때문에 선택 fold로 쓸 수 없습니다
(앞선 앙상블 실험에서 승인받은 규율과 동일).

## 5. 예상

| 결과 | 확률 |
|---|---|
| Stage 0에서 "2023 고유" 판정 → 종료 | ~35% |
| Stage 1 진행 후 E0-1 실패 (BSS < 827.3) | ~30% |
| E0-3 실패 (상한 개선 < +10) | ~30% |
| **E0 통과** | **~5%** |

근거:

1. **2024 상한이 +25.6**입니다. BCAT를 완벽 교정해도 그렇습니다. E0-3이 요구하는
   stacking 상한 +29.4는 그 위이므로, variant가 단순히 "더 잘 교정된 BCAT"라면
   통과할 수 없습니다. 통과하려면 **다른 정보**를 가져와야 합니다.
2. 앞선 calibration 감사에서 확인했듯 **교정은 시즌 간 전이되지 않습니다**
   (2023→2024 −100 ~ −141, 6/6 음수). BCAT의 상단 꼬리 문제도 같은 성질일
   가능성이 높습니다.
3. 직전 E0(XGBoost)에서 확인했듯 **같은 입력 공간에서 알고리즘·설정만 바꾸면
   다양성이 생기지 않습니다.** variant 3종 모두 `b_feats` 68개를 그대로 씁니다.

## 6. 권고

**Stage 0만 수행하십시오.** 30분이고 학습이 없습니다.

Stage 0의 가치는 게이트 통과 여부가 아니라 **2025 리스크 판정**입니다. BCAT는
weight 0.45로 v9에서 가장 무거운 구성요소이고, 2023에 한 번 붕괴했습니다.
그것이 재발 가능한 구조적 병리인지 2023 고유 사고인지는 **제출 전에 알아 둘
가치가 있습니다** — 점수를 올리기 위해서가 아니라, 올리지 못할 것을 확인하고
넘어가기 위해서입니다.

Stage 0 결과에 따라:

- **2023 고유 사고** → 종료. 기록만 남기고 `submit_v9.zip` 유지
- **구조적 병리** → Stage 1 설계 제출 후 승인받아 진행

어느 경우에도 **제출본은 변경하지 않습니다.** E0를 통과하더라도 새 번들 제작은
별도 논의 대상입니다.
