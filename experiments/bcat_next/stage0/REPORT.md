### 1.3 같은 행에서 A7/A9는 정상입니다

```
p_Bcat   0.6801   실제 0.4755   gap -0.2045     <-- BCAT 만 붕괴
p_A7     0.5076   실제 0.4755   gap -0.0321

```

**같은 24,553행에서 A7/A9는 각각 −0.03, +0.01로 정상**입니다. 데이터가 어려운
구간이어서가 아니라 **BCAT 고유의 과신**입니다.

### 1.4 원인 — entity overconfidence

세 가지가 한 방향을 가리킵니다.

1. BCAT만 `pitcher_id_num` / `batter_id_num`을 직접 씁니다 (`b_with_ids=True`)
2. 붕괴 구간은 **표본이 적은 투수**에 집중 (asof_n 1,311 vs 3,351)
3. 같은 행에서 ID를 쓰지 않는 A7/A9는 멀쩡

**표본이 적은 엔티티에 대해 CatBoost의 target statistic이 극단적 확신을 만들었고,
홀드아웃에서 그것이 기저율로 회귀한 것**입니다. leakage는 아니지만 그와 유사한
과신 패턴입니다. 평균 모델이 2개뿐인 것(A7/A9는 각 12개)도 분산 억제를 약하게
합니다.

## 4. 결론

### 판정 A — 2023 고유 사건

- 2024에 같은 profile이 **없습니다** (절대 임계 0.3%·gap −0.02, 분위 위치 gap **+0.006**)
- 2023 붕괴 구간의 **같은 투수들이 2024에서는 정상** (gap −0.0022)
- 2024 BCAT는 붕괴 임계(0.617) 근처를 거의 예측하지 않습니다 (최대 0.660)

**BCAT 수정 연구를 종료합니다.** Stage 1(variant 학습)로 넘어가지 않습니다.

### 다만 기록해 둘 것

원인은 **표본이 적은 엔티티에 대한 과신**으로 특정됐습니다. `b_with_ids=True` +
CatBoost target statistic + 평균 모델 2개의 조합입니다. 2024에서 발현하지 않은
이유는 2024 fold의 학습 데이터가 한 시즌 더 많아(2019–2023 vs 2019–2022) 엔티티당
표본이 늘었기 때문일 가능성이 높습니다.

**2025 제출 모델은 2019–2024 전체로 학습되므로 표본이 더 많습니다.** 즉 2023보다
2024에 가까운 조건이며, 재발 확률은 낮다고 판단합니다.

### 방어선을 걸지 않는 이유

시뮬레이션이 명확합니다. 2024에서 비용이 0인 방어선(`clip <= 0.65`)은 2023을
절반만 구하고, 2023을 제대로 구하는 방어선은 2024에서 −8 ~ −37을 냅니다.
**2025가 2024형이라면 방어선은 순손실**이고, 위 분석은 2025가 2024형일 가능성이
높다고 말합니다.
