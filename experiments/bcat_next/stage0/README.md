# Stage 0 — BCAT 2023 collapse 진단

**판정: A (2023 고유 사건). BCAT 수정 연구 종료. Stage 1 미실행.**

## 무엇을 물었나

v9의 BCAT는 weight 0.45로 가장 무거운 구성요소입니다. 2023 fold에서 그 예측의
상위 2개 bin이 Reliability 1777.6의 95.9%를 만들었고(0.65~0.71 예측, 실제 기저율),
2024에서는 같은 모델이 Reliability 28.2로 깨끗합니다.

**점수를 올리려는 조사가 아니라, 2025에 재발하는가를 묻는 조사입니다.**

## 답

재발하지 않을 것으로 판단합니다.

| 확인 | 2023 | 2024 |
|---|---|---|
| 상위 10% gap | **−0.2045** | **+0.0057** |
| 절대 임계 `p >= 0.6172` 행 | 10.0% | 0.3% (gap −0.02) |
| 붕괴 구간 투수들의 gap | −0.2045 | **−0.0022** |
| p_Bcat 최대 | 0.7821 | 0.6601 |

원인은 **표본이 적은 엔티티에 대한 과신**입니다 — 붕괴 구간의
`asof_pitcher_n` 중앙값이 1,311로 정상 구간(3,351)의 39%이고, 같은 행에서
ID를 쓰지 않는 A7/A9는 정상이었습니다. 2025 제출 모델은 2019–2024 전체로
학습되어 표본이 더 많으므로 2023보다 2024에 가까운 조건입니다.

## 방어선을 걸지 않는 이유

```
              2023 dBSS   2024 dBSS
clip <= 0.65     +98.5       -0.0
cap 0.08        +267.3       -8.1
shrink x0.7     +176.1      -37.0
```

2023을 구하는 방어선일수록 2024에서 더 잃습니다. 두 시즌을 동시에 만족하는
상수가 없고, 2025는 2024형일 가능성이 높습니다.
